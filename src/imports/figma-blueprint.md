🎨 Design System (Student-Centric)
Element	Recommendation
Color Palette	Primary: Friendly Blue (#4A90E2) or Growth Green (#2ECC71). Accent: Soft Yellow for highlights.

🛠️ Page-by-Page Figma Blueprint
Page 1: Main Page (Gateway)
The "Main Page" acts as the entry point. It needs to be clean to avoid overwhelming the student.

Hero Section: A welcoming heading like "What are we learning today?"

Login Card: A centered, floating white card with:

Input fields for "Student ID / Email" and "Password."

A prominent "Login" button.

Navigation: Two large, illustrative cards or buttons side-by-side:

Student Resources (Icon: A book or graduation cap).

Pre-Resources (Icon: A pencil or lightbulb).

Page 2: Category Selection (SLC vs. CBSE)
Layout: A simple split-screen or two large grid cards.

Visuals: Use the official logos for SLC and CBSE to make the choice instant for the user.

Navigation: A "Back to Home" breadcrumb in the top left.

Page 3 & 4: The Class Grid (The Content Hub)
Your sketch shows a vertical list for Classes 1–10. In Figma, a Grid Layout usually works better for modern screens.

Sidebar: Keep a persistent sidebar showing the current curriculum (e.g., "CBSE Resources") so the student doesn't feel lost.

Class Cards: 10 interactive cards arranged in a 2×5 or 3×4 grid.

Each card should have the class number (e.g., "Class 10") in a bold, large font.

Hover effect: The card should slightly lift or change color when the mouse is over it.

✨ Figma Implementation Tips
To make this look professional in Figma, follow these steps:

Auto Layout: Use Figma’s "Auto Layout" (Shift + A) for the Class 1–10 list. This ensures that if you add "Class 11" later, the spacing remains perfect automatically.

Components: Create one "Class Card" component and use instances for 1–10. If you decide to change the color of one, they all update at once.

Prototyping: * Link the "Student Resources" button on Page 1 to Page 2.
